# Poriadok — дизайн-система v3

Затверджено 09.11.2026. Джерело правди в коді: `frontend/src/mobile.css` (блок «v3» внизу перекриває основу). Макет-еталон: https://claude.ai/artifact/46W1BuqSE4vU1yvkV3i76H

## Принципи

- Сірий фон, вміст на білих плашках. Плашка = група. Тіней на плашках нема.
- Один темний акцент на екран: головна картка (найближча подія, поточний місяць) або активний стан (вкладка, обраний день, кнопка дії).
- Колір лише функціональний: червоний — протерміновано, 0 записів, небезпечні дії; зелений — статус «ок».
- Жодних тонких накреслень. Мінімум 500, цифри 700.
- Тексти інтерфейсу малими літерами. Тире — em-dash без пробілів, апостроф ʼ, лапки «…».

## Відступи й форма

- Поля сторінки 16px; заголовки груп мають внутрішній відступ 6px, щоб стояти по лінії тексту плашки.
- Між групами 28px, підпис групи над плашкою 10px, між плашками в ряд 8px.
- Радіуси: плашка 24, темна картка 28, плитка 20–24, поле 16, пігулка = висота/2, шторка 28 зверху.
- Рядок списку ≥ 62px, падінг плашки 18px по боках. Зони натискання ≥ 44px.

## Компоненти

- **Плашка-список** `.m-list` — біла, r24, рядки `.m-row` з лінією `--m-line` між ними.
- **Темна картка** `.m-hero` — чіп `.m-hero-chip`, назва, велика цифра, шкала з 10 сегментів `.m-hero-seg`.
- **Плитки** `.m-tiles` / `.m-tile` — 2 в ряд: велике число + підпис; стрілка ↗ якщо плитка веде кудись.
- **Метрики** `.m-metrics` — 3 білі плитки в ряд.
- **Пігулки** `.m-tab` — 40px; активна чорна з білим текстом; лічильник — червоний бейдж.
- **Кнопки** `.m-btn` 54px чорна; `.m-ghost` 40px біла (у шторці `--m-soft`), активна чорна; `.m-txt` текстова 600.
- **Поле** `.m-field` — плашка r16: підпис 13/600 сірий, значення 16/500; фокус — чорний контур 1.5px.
- **Перемикач** `.m-switch` 50×30, увімкнений чорний.
- **Чекбокс** `.m-chk` 24px, контур 2px `#D6D6D3`; протермінований — червоний; виконаний — чорний з білою галкою.
- **Статус** `.m-dot` 7px: зелений / сірий `--idle` / червоний `--warn`.
- **Календар** — біла плашка; сьогодні — чорний квадрат r14; обраний — чорний контур; день з подією — крапка 5px.
- **Док** `.m-nav` — чорна плаваюча панель 64px r32, іконки 22px stroke 2, активна в білому колі 48px; підписи лише для скрінрідера. `.m-fab` — біле коло 64px праворуч від доку.
- **Шторка** `.m-sheet` — біла, r28 зверху, ручка 36×5.
